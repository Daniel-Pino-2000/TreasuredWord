# TreasuredWord 1.7 (versionCode 8): release notes

"What's new" text for the Google Play closed testing release of 1.7 (#264). Each language's
text has to stay within Play's 500-character limit. Paste the block below into the release's
notes box; Play matches each `<tag>` to a store listing language.

What's in it since 1.6 (versionCode 7): the Bible Helper, now on in release builds (#120,
#131), color themes (#244), the daily verse home screen widget (#245), verse images
(#254–#257), smoother rotation and keyboard (#238–#241), readable highlights and Settings rows
(#246, #248, #249), Library's swipe-to-delete (#243, left out of the notes to stay under the
limit) and the Android 7–11 startup crash fix (#262).
