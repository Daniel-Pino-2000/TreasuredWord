# TreasuredWord 1.8 (versionCode 9): release notes

"What's new" text for 1.8, the release on the closed testing track that is promoted to
production once Google grants production access. Each language's text has to stay within Play's
500-character limit. Paste the block below into the release's notes box; Play matches each
`<tag>` to a store listing language.

What's in it since 1.7 (versionCode 8): the verse of the day never repeats the day before's,
and the widget and daily wallpaper catch up when the app opens (#298); Library's Undo works again
(#270); Bible Helper answers arrive more reliably (#280), the chat keeps its place after opening a
verse (#278), a question about a verse keeps it when the conversation is reopened (#281), verse
markers closed with one bracket no longer show raw codes (#294) and the daily-limit message is
clear (#271); the widget's verse fits its size (#272); the selection toolbar's centering (#269) and
the Korean rail label in landscape (#266).
